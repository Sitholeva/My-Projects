My First CSS Project
Overview
This project is my first step into styling web pages using CSS. It complements my HTML by adding colors, layouts, and design to make the page look better.

Features
Basic CSS styling (colors, fonts, spacing)

Layout adjustments using CSS

Styling of text, links, and images

External CSS file linked to HTML

How to Use
Download or clone the project files.

Open the index.html file in a web browser to see the styled page.

Inspect the styles.css file to understand how the styling works.

What I Learned
How to link an external CSS file to HTML

Basic CSS properties like color, font-size, margin, and padding

How to improve the look and feel of a webpage with CSS
